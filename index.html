    How this AI works

    1

    Hybrid retrieval

    Embeds your query locally and runs it through both BM25 keyword search and vector search over Rahul's documents, fusing the two result lists.

    2

    Reranks the context

    A local cross-encoder reranks the fused candidates so only the most relevant passages from Rahul's resume, projects, and notes reach the model.

    3

    Generates grounded answers

    An open model served via OpenRouter answers from the retrieved passages. Follow-up questions work too: the conversation is condensed into a standalone query first.

    Built with LlamaIndex, OpenRouter, and local embeddings + reranker (ONNX, zero per-query API cost)
